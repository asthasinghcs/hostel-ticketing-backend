## Reproduce the demo

From the backend directory, set DATABASE_PATH to an intended local or demo database. Back up existing data before a release. Then run:

```powershell
python seed.py --append-demo
```

This adds the fixed batch once, without deleting or replacing existing users or tickets. Repeating the command detects the batch and does not duplicate records, reset passwords, or redate tickets. A conflicting email aborts the complete import. On a fresh empty database, python seed.py also loads the same 40-record demo.

For repeatable dates in a fresh demonstration database:

```powershell
python seed.py --as-of 2026-10-27T09:54:35Z
```

The loader distributes dates across seven campus calendar dates ending at the seed anchor. A previously imported batch keeps its original dates. The JSON fixture contains relative age weights; recent-grievances.sample.json records the concrete dated sample. Ticket IDs can differ in a fresh database.

The database and its backup stay out of Git. The fixture, account guide, example snapshot, migration code, and tests are versioned. Importing the fixture into a hosted database requires running the seed command there; pushing source does not change hosted records.
